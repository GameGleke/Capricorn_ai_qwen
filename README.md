# Капри 🌸

Голосовой AI-ассистент для Windows с анимированным аватаром-«цифровой личностью» в киберпанк-стиле (Найт-Сити).
Живёт на рабочем столе: появляется по голосу («Капри»), слушает через микрофон, отвечает русским голосом и выполняет команды.

## Возможности
- **Голосовое управление**: wake-word «Капри», офлайн-распознавание речи (Vosk) + уточнение через Google STT.
- **Команды ПК**: открытие сайтов и приложений, громкость, яркость, поиск в Google/YouTube, перемотка видео по времени, управление музыкой (SMTC Windows), диагностика ПК, автонабор текста в окнах.
- **Интеллект**: **бесплатная Qwen 3.5 9B с Hugging Face через llama.cpp** (`setup_llama.bat`, без Ollama, без torch, офлайн после скачивания ~5 ГБ GGUF); альтернативы — Ollama (`setup_ai.bat`) или transformers (`setup_hf.bat`); опционально Claude (Anthropic API) с веб-поиском.
- **Персона**: характер, свои ответы на фразы, обращение по имени/роду, «болтовня» от скуки.
- **Аватар**: прозрачное окно поверх всех окон с глитч-эффектами, субтитрами и анимациями.
- **Голос**: edge-tts (Microsoft neural voices) с обработкой (pitch/prosody/Silero), glitch-звуки.
- **Нюансы РФ**: автоматическая починка голоса при работе zapret (winws.exe).

## Быстрый старт (Windows)
1. Установите Python 3.11–3.14 (лучше 3.13; 3.15+ пока не поддерживается голосовой библиотекой).
2. Запустите `setup.bat` — поставит зависимости и модель Vosk (из `bundled/`, интернет не нужен).
3. (Опционально, рекомендуется) `setup_llama.bat` — разум на **бесплатной Qwen 3.5 9B с Hugging Face**
   через llama.cpp: без Ollama, сам подберёт размер модели под железо, скачает GGUF и проверит ответы.
   Старые варианты: `setup_ai.bat` (Ollama + qwen3) или `setup_hf.bat` (transformers — нужен свежий
   transformers >= 4.57 и ~16-18 ГБ RAM; weights safetensors ~18 ГБ, качаются один раз).
4. Запустите `run.bat`. Скажите «Капри» или кликните по иконке в трее.

Настройки — в `config.json` (создаётся автоматически): сайты, программы, голос, микрофон, имя пользователя и т.д.
Полный список голосовых команд — в [КОМАНДЫ.md](КОМАНДЫ.md).

## Структура проекта
| Файл | Назначение |
|---|---|
| `main.py` | Ядро: запуск, конфиг, трей, цикл «слушаю → команда → ответ», планировщик болтовни |
| `voice.py` | Распознавание речи (Vosk + Google STT), синтез (edge-tts), обработка голоса, звук глитча |
| `actions.py` | Разбор и выполнение команд: сайты, приложения, громкость/яркость, YouTube, диагностика ПК |
| `automation.py` | Win32-автоматизация: ввод текста (SendInput), окна, клики, горячие клавиши |
| `media.py` | Управление текущим плеером через Windows SMTC (пауза, перемотка, «что играет») |
| `ai.py` | Ответы через Claude API с серверным веб-поиском |
| `local_ai.py` | Ответы через локальную Ollama (qwen3), автовыбор модели, фолбэк на поиск |
| `hf_backend.py` | Тот же разум через бесплатную Qwen 9B с Hugging Face (transformers), общий интерфейс с local_ai |
| `tools/hf_worker.py` | Отдельный процесс инференса HF-модели (torch/CUDA вне Qt) |
| `tools/install_hf.py` | Установка transformers + скачивание весов + настройка config.json |
| `persona.py` | Характер Капри: системный промпт, реплики, род/имя пользователя |
| `avatar.py` | Прозрачный HiDPI-аватар с глитч-анимациями, позами и субтитрами |
| `zapret.py` | Обход поломки голоса Microsoft из-за стратегий zapret (исключения winws) |
| `entries_dialog.py`, `profile_dialog.py`, `sound_dialog.py` | Диалоги настроек: свои сайты/программы/ответы, обращение, звук |
| `tools/` | Установка (install.py, install_ai.py, download_model.py), сборка релиза, конвертация анимаций, генерация медиа |
| `assets/` | PNG-кадры анимаций и позы Капри |
| `bundled/` | Архив модели Vosk (Apache 2.0) для установки без интернета |
| `media/` | Картинки/гифки для README и превью |

## Технологии
Python 3.11+, PySide6 (Qt), Vosk, edge-tts, SoundDevice, psutil, Pillow, numpy, Anthropic SDK, Ollama, WinRT (SMTC), ctypes/Win32.
